# Contributing

Contributions and focused bug reports are welcome.

## Development setup

```bash
git clone https://github.com/the-jey/codex-sub-imagen.git
cd codex-sub-imagen
npm install
npm run check
pi --no-extensions -e .
```

## Pull requests

1. Keep changes focused and backward-compatible when practical.
2. Never include credentials, private reference images, or generated assets.
3. Run `npm run check` before submitting.
4. Update the README and changelog when behavior or public parameters change.
5. Explain how the change was validated.
